# Diseño: material de origen

Material recibido del propietario el 2026-11-12 para el sistema de diseño y el rebranding (ADR-020, spec S-19). **No es el sistema de diseño**: es su insumo.

## Qué hay aquí
- `origen-logotipo/LEEME-kit-logotipo.txt`: el LEEME original del kit de logotipo (archivos incluidos, colores y nota técnica).
- `origen-logotipo/favicon-adhara-fit.ico`: favicon multirresolución con 7 imágenes (16, 24, 32, 48, 64, 128 y 256 px).

## Qué NO hay todavía
Los PNG del kit (logotipo horizontal en color, negativo y monocromo; isotipo; iconos de 32 a 1024 px; tamaños de 600, 1200 y 2400 px) se recibieron solo como imágenes dentro del chat, convertidas, y **no se versionan**: son copias, no los originales. El propietario debe entregarlos como archivos cuando empiece S-19.

## Datos confirmados por el kit
- Colores: carbón `#231F20`, amarillo `#FFCB04` y blanco `#FFFFFF`. El isotipo recibido mide `#FFCB04`.
- El logotipo es un kettlebell amarillo con una «A» blanca más el nombre «ADHARA FIT» en negrita; hay versión para fondo claro (nombre en carbón), para fondo oscuro (nombre blanco) y monocromas.

## Limitación importante
El archivo de origen del logotipo es un SVG que contiene un PNG incrustado: **no es vectorial**. Para el sistema de diseño hay que redibujar o vectorizar el logotipo y el isotipo (S-19). La tipografía del nombre no está identificada.
